# Jitter Randomization

## The Idea

**What**: Add controlled randomization to output parameters - jitter dot positions, randomize flower petal orientations, offset shapes from grid centers, vary sizes within ranges.

**Why**: Creates organic, hand-crafted aesthetics instead of perfect mechanical grids. Can simulate natural printing imperfections, artistic effects, or decorative patterns with deliberate irregularity.
