# SVG Output Mode

## The Idea

**What**: Generate SVG files instead of raster/pixel images - output halftone patterns as vector graphics with true circles, paths, and shapes.

**Why**: Vector output enables infinite scaling, smaller file sizes, precise editing in tools like Illustrator/Inkscape, and opens creative possibilities like laser cutting, CNC routing, or pen plotting.
