## Description

Visual diff image generation for QA review

Generate a diff image that highlights regions of the source image not captured by the detected circles, making it easy for reviewers to spot missed detections at a glance.

**Value**: Enables rapid visual QA by showing exactly what was missed during circle detection, helping users identify areas that may need parameter tuning or manual review.

**Target Users**: Users reviewing detection quality, tuning parameters, and performing QA on halftone extraction

**Estimated Effort**: 1 day

## Implementation Plan

### Overview

Add a `generate_diff_image()` function to `image_extractor.py` that compares the source image to detected circles, creating a mask of uncovered regions. The diff will be generated automatically in the main CLI flow when outputting to a directory.

### Implementation Steps

1. **Add `generate_diff_image()` to image_extractor.py**: 
   - Create mask from all detected circles
   - XOR or subtract from source image regions
   - Highlight missed regions with red/magenta overlay
   - Save as `diff.png` in output directory

2. **Add CLI flag `--no-diff`**:
   - Boolean flag to disable diff generation
   - Default is to generate diff when using `--output-dir`

3. **Integrate into main CLI flow**:
   - Call after composite generation
   - Add diff path to manifest under outputs

4. **Add unit tests**:
   - Test diff generation with known circles
   - Test that missed regions are highlighted
   - Test `--no-diff` flag works

### Technical Considerations

- **Performance**: Mask creation is O(circles * image_size), but since we're already iterating for composite, overhead should be minimal
- **Memory**: For large images, may need to create mask in chunks similar to chunked detection
- **Color choice**: Red/magenta overlay on grayscale diff of source provides good contrast

### Dependencies

- PIL/Pillow (already in use)
- NumPy (already in use)
