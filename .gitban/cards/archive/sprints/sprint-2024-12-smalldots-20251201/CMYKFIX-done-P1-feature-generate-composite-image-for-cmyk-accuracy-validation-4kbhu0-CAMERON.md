## Description

Generate composite image from detected CMYK circles for visual accuracy validation.

After separating CMYK layers and detecting circles in each channel, generate a "reconstituted" composite image that overlays all detected circles. This allows users to visually compare the detection accuracy against the original halftone image.

**Value**: Enables human QA verification of circle detection accuracy by providing side-by-side comparison of original vs. reconstructed image. Critical for tuning detection parameters and validating results.

**Target Users**: Users processing halftone images who need to verify detection quality.

**Estimated Effort**: 2-4 hours

## Implementation Plan

### Overview

Add a `generate_composite_image()` function to `image_extractor.py` that combines all detected circles into a single image. Call this from `cli.py` after CMYK layer generation when extraction is enabled.

### Implementation Steps

1. **Add composite generation function**: Create `generate_composite_image()` in `image_extractor.py`
   - Takes `circles_with_colors` and `image_shape` as input
   - Creates RGBA image with transparent background
   - Draws all circles at detected positions with detected colors
   - Returns path to saved `composite.png`

2. **Integrate into CLI**: Update `cli.py` extraction logic
   - Call `generate_composite_image()` after `generate_cmyk_layer_files()`
   - Add `--no-composite` flag to disable
   - Include composite path in output files list

3. **Update manifest**: Include `composite.png` in manifest output_files

4. **Add tests**: Integration tests verifying composite generation

### Technical Considerations

- **Performance**: Single pass through circles list, minimal overhead
- **File Format**: PNG with alpha channel for transparency
- **Color Fidelity**: Use exact detected RGB colors, not remapped palette colors

## Notes

### Design Decisions

- **Transparent background**: Chosen over white/black to allow easy overlay comparison in image editors
- **Default enabled**: Most users want this for QA, disable with flag if file size is concern
- **Same directory as layers**: Keep all outputs together in organized run directory
